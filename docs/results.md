# 实验与验收报告

Windows CPU 上完成 3 组各 16,384 步的奖励对照和 1 组 32,768 步追加实验。交付模型来自 `exp_20261103_death_02`，使用采样动作。固定种子各评 10 局，模型最远 1959，随机基线最远 898，相当于 2.18 倍。平均奖励分别为 613.0 和 460.1。本轮未以通关为验收门槛。

## 实验条件

- Windows x64，AMD Ryzen 9 7940H，15.22 GiB 可见物理内存。Python 3.11.18，PyTorch 2.7.1+cpu，Stable-Baselines3 2.7.1。
- World 1-1，七动作，4 帧动作重复，灰度 84×84 四帧堆叠。每局最多 1200 个决策步。
- 原始奖励、正向距离额外奖励与死亡惩罚三组使用相同环境数量、训练预算、模型和种子。组合参数组同时改变训练预算、奖励和 PPO 参数，单独记录。
- 评测种子为 42～51，额外复核使用 4242～4251。各组使用相同基础奖励。表中的奖励为十局均值与总体标准差。
- 从均值高于随机的候选中选择最远距离最高的一组，距离相同用平均奖励决胜。模型选择使用首组种子，第二组种子保留作复核。

## 指标验收

| 指标 | 实测 | 结论 |
|---|---|---|
| 最远距离达到随机 3 倍 | 1959 ÷ 898 = 2.18 | 未达成 |
| 奖励高于随机并呈稳定学习趋势 | 首组种子差 +152.9，训练曲线前 5 个统计点均值 293.8，末 5 点均值 660.3 | 均值高于随机，曲线稳定收敛仍需更长训练与多训练种子 |
| 约百万步不超过 3 小时 | 当前最长完整单轮 32,768 步 | 百万步未验证 |
| 评测吞吐至少 30 FPS | 172.7 决策步/秒 | 达成 |
| 评测内存峰值不超过 8 GB | 0.33 GiB，Windows 进程峰值工作集 | 达成 |
| 通关率 | 0% | 如实记录 |

评测 FPS 以计时区间的策略决策步数计算，排除录像编码。原始录像每四个模拟器帧保留一帧，以正常游戏速度播放。
