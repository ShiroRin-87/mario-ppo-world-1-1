# 独立测试报告

测试环境为 Windows x64、Python 3.11.18 和 CPU 版 PyTorch 2.7.1。环境、训练、评测与打包角色由同一执行者在独立目录复跑。原始命令输出随交付包存放于 `data/test-evidence/`。

| 用例 | 结论 | 复现与证据 |
|---|---|---|
| T01–T03 安装与冒烟 | 通过 | 安装锁定依赖后执行 `python -m pip check` 和 `python scripts/smoke_test.py`。两次实测均为 100 步、7 动作、最远 155、奖励 110 |
| T04–T09 环境契约 | 通过 | `python -m unittest discover -s tests -v`，五项均通过，覆盖复位、步进、动作、观测、RGB 和截断 |
| T10–T11 短训与续训 | 通过 | 512 步训练写出模型、日志、配置和 TensorBoard。从 512 步存档续训到 1024 步 |
| T12–T13 训练后与随机评测 | 通过 | 两种策略均产出规定的 JSON 字段和十局明细。H3 复跑了同种子模型结果 |
| T14–T15 录屏与曲线 | 通过 | FFprobe 校验两段实录和 3～5 分钟成片。曲线用真实 CSV，含坐标与实验号 |
| T16–T18 错误配置、模型及 ROM | 通过 | 非映射 YAML、缺失 YAML、缺失与损坏权重均非零退出。隔离副本缺 ROM 时报告具体路径 |
| T19 模拟磁盘满 | 通过 | 在保存方法注入 ENOSPC，已有模型内容保留。该项为故障注入 |
| T20 实际中断与恢复 | 通过 | 独立训练进程在 256 步存档后终止，重新加载后续训至 768 步 |
| T21 百万步耗时 | 未验证 | 只记录实际完成步数与墙钟。八子进程分配失败的日志与后续重跑记录一并保存 |
| T22 评测速度与内存 | 见实测 | 决策吞吐、进程峰值工作集与计时口径见 [实验报告](results.md) |
| T23 策略对比 | 部分达成 | 用同配置和种子比较。奖励与最远距离实测见 [实验报告](results.md) |
| T24 干净目录解包 | 通过 | 新目录解包，复用已验证的隔离 CPU 环境核对依赖和冒烟，512 步短训、续训至 1024、十局评测与完整视频解码均通过。见 `data/test-evidence/release-verify-*.log` |
