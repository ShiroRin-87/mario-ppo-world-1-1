# 独立验收用例

每条执行记录填写日期、提交、命令、预期、实际、结论与证据路径。训练、评测和录屏相关用例在 H2/H3 的模型与脚本到位后执行。

| 编号 | 类型 | 操作 | 预期 |
|---|---|---|---|
| T01 | 功能 | 新目录安装锁定依赖 | 安装成功且 pip check 通过 |
| T02 | 功能 | 执行 100 步冒烟 | 输出 PASS 和步数 |
| T03 | 功能 | 重复同种子随机冒烟 | 结果一致 |
| T04 | 功能 | 检查 reset 和 step 返回值 | Gymnasium 两项、五项格式 |
| T05 | 功能 | 枚举七个动作 | 均可执行且越界动作报错 |
| T06 | 功能 | 检查观测尺寸与 dtype | 4×84×84 uint8 |
| T07 | 功能 | 复位帧堆叠 | 初始历史与当前局一致 |
| T08 | 功能 | 检查 rgb_array | 返回可录制 RGB 帧 |
| T09 | 功能 | 观察终止与最大步数 | terminated 与 truncated 按原因区分 |
| T10 | 功能 | 运行短训 | 写出日志、配置副本及模型 |
| T11 | 功能 | 载入 checkpoint 继续短训 | 训练步数从存档继续累加 |
| T12 | 功能 | 用模型评测 | JSON 字段齐全，数字有限且局数正确 |
| T13 | 功能 | 执行随机评测 | 输出同结构 JSON 并标明随机策略 |
| T14 | 功能 | 生成并解码录屏 | MP4 可打开，画面为实际对局 |
| T15 | 功能 | 查看训练曲线 | 有实验编号和坐标轴 |
| T16 | 异常 | 提供缺失或错误 YAML | 非零退出并指出配置问题 |
| T17 | 异常 | 提供缺失或损坏模型 | 非零退出并指出模型加载问题 |
| T18 | 异常 | 在隔离副本模拟 ROM 缺失 | 安装或环境检查给出错误证据 |
| T19 | 异常 | 在隔离输出目标模拟磁盘满 | 非零退出，已存在模型仍可用 |
| T20 | 异常 | 训练中断后续训 | 最近成功存档可用 |
| T21 | 性能 | 记录实际训练步数和墙钟 | 约百万步三小时内为目标，记录偏差 |
| T22 | 性能 | 测量模型评测 FPS 和内存 | FPS ≥30，内存峰值 ≤8 GB 为目标 |
| T23 | 验收 | 同设置评估随机与训练后策略 | 核对距离倍数、奖励与通关率 |
| T24 | 验收 | 干净目录解包按 README 执行 | 安装、训练、评测与演示均可复现 |
