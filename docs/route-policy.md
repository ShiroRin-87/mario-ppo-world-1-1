# World 1-1 专用通关策略

状态近邻策略从种子 42 的成功对局提取 400 个状态和动作样本。每步读取马里奥位置、移动速度、动作保持时长和缩小的画面，选出最相似状态对应的动作。策略用本地 CPU 推理。训练示范由采样 PPO 和原 609 参数排序模型生成。

## 验证

| 起点条件 | 通关 | 最远位置 |
|---|---:|---:|
| 标准开局 | 1/1 | 3161 |
| 原地等待 1 至 31 个决策步，共 10 种时长 | 10/10 | 3161 |
| 手柄输入使开局位置或姿态发生变化，共 4 组 | 0/4 | 681 |

等待组覆盖 1、3、5、7、9、11、13、17、23、31 步。每种初始模拟器 RAM 校验值不同，马里奥起点保持 x=40。通关各用 400 个策略决策步。移动扰动组都在 x=679～681 结束。

前序调试里，原排序器对留出种子 4242～4251 的通关为 0/10，平均最远位置 1083.1。先用小模型选出两项再延长预演，平均最远位置为 1237.0，通关为 0/10。两种排序策略使用相同种子。它们和上表的起点扰动是分别执行的实验。

## 复现

在项目根目录使用训练环境运行。生成近邻模型需要已有的 PPO 模型和首轮 `decision-ranker.pt`。

```powershell
python train/train_route_policy.py --ranker <decision-ranker.pt> --output logs/exp_20261103_route_01
```

也可直接加载已保存的模型。输出的 JSON 保留动作前缀、初始状态校验值、距离和旗标。

```powershell
python train/train_route_policy.py --route-model <world-1-1-route.npz> --output logs/exp_20261103_route_verify_01
```

该策略用于 World 1-1 从标准出生点开始的演示。开局被提前移动时，模型在当前四个测试条件下需要更强的恢复能力。
