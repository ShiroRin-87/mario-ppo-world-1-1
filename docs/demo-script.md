# 超级马里奥项目演示分镜

成片计划约四分钟。数值、画面、实验编号与结论在实测后填写。

| 时间 | 画面与录制点 | 旁白 |
|---|---|---|
| 0:00–0:30 | World 1-1 实录，展示智能体越过或尝试越过障碍 | 我们让智能体通过画面学习七个手柄动作，目标是比随机策略走得更远。 |
| 0:30–1:10 | 原始彩色帧与四帧预处理对照，架构图 | 环境每次重复动作四步，把图像压成 84×84 灰度并堆叠四帧。PPO 使用小型 CNN 决定下一步动作。 |
| 1:10–1:50 | 实际训练命令、配置和 TensorBoard，放大曲线横纵轴 | 这一轮用【实验编号】记录了配置、种子和提交，耗时【实测】。曲线展示训练中奖励的变化。 |
| 1:50–3:10 | 同关卡随机策略与训练后策略并排回放，叠加评测 JSON 的距离和平均奖励 | 两种策略使用同一关卡和评测条件。随机策略最远到【实测】，训练后最远到【实测】。 |
| 3:10–3:45 | 一段真实失败录像，冻结在失败动作 | 这里出现了【现象】。结合日志，我们推测【原因】。可以用【下一次对照实验】验证。 |
| 3:45–4:00 | README 三条命令和最终清单 | 按文档可以复跑安装、训练和评测。报告记录了已测结果和仍有差距的指标。 |
