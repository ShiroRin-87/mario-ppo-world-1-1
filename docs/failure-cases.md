## 开发缺陷

| 编号 | 现象与证据 | 原因与处理 | 状态 |
|---|---|---|---|
| D01 | 默认解释器为 Python 3.12 | 规范为 3.10/3.11，部署隔离的 3.11.18 | 已处理 |
| D02 | 安装下载出现 TLS 提前关闭 | 按原索引重试，使用校验过的缓存包 | 本机已绕过 |
| D03 | Windows 前进奖励组在更新时报 NumPy 6.89 MiB 分配失败 | 8 个子进程开销叠加。改用 4 个单进程环境，三个受控对照均复跑完成 | 已处理 |
| D04 | 贪心模型十局早停，最远距离小于随机 | 贪心重复同类动作。增加带固定种子的策略采样入口，报告分别列贪心与采样 | 已记录 |
| D05 | 首组种子最远距离为随机 2.18 倍 | 短训与单训练种子覆盖有限，后续扩大训练预算和随机种子 | 未达成指标 |
